# 福岡パソコン通信・局候補メモ

## よかネット

**Status:** existence confirmed / oral-history lead says 絵理香 / contemporary 1988 network reference found / raw log not yet found

株式会社BCCの公式沿革には、1985年10月に「NEC-NET福岡通信センター設置」、
1986年4月に「パソコン通信クラブ『よかネット』運営」とある。

Source:
https://www.bcc-net.co.jp/company/history.html

1988年7月の『情報管理』Vol.31 No.4では、地方公共団体が関与する地域ネットワークの実施例として「よかネット（福岡市）」がCOARA等と並んで掲載されている。サービス開始から約2年後の同時代資料として、名称・地域・活動時期の強い裏付けになる。

Source:
https://www.jstage.jst.go.jp/article/johokanri/31/4/31_4_309/_pdf/-char/en

別のホストプログラム資料では、絵理香および絵理香K版がBCC系ソフトとして記録されている。

Source:
https://www.wdic.org/w/TECH/%E3%83%9B%E3%82%B9%E3%83%88%E3%83%97%E3%83%AD%E3%82%B0%E3%83%A9%E3%83%A0

### Oral-history lead

研究中の口述情報として「よかネットは絵理香だった」という記憶が得られている。
BCCがよかネットを運営していたこと、絵理香がBCCと結び付けられていることとは整合するが、
局の実ログ、画面写真、マニュアル、電話帳記載等で直接確認できるまでは
host program = 絵理香を確定扱いしない。

- BCC社内資料、会報、操作説明書

## めんたいネット

**Status:** existence confirmed / public 2005 reminiscence directly says 絵理香 / oral-history lead says 絵理香K版 / raw log not yet found

2007年のITmediaによる矢野さとる氏への取材で、中学時代に
「地元のISP『めんたいネット』でパソコン通信を楽しみ」と記録されている。
記事では矢野氏が福岡出身であることも確認できるため、1990年代半ばの
福岡ローカルISP/パソコン通信サービスとして扱う。

Source:
https://www.itmedia.co.jp/news/article/0703/12/1070312039/

### Direct public evidence for 絵理香

2005年の人力検索はてなの質問者が、めんたいネットを「『絵理香』で運用されていたパソコン通信のホスト」と明記している。質問者は当時 K-writer / カメンライタというHNを使っていたとも記し、回答への返信では shibata氏と「1992年くらいにChat」したと回想している。回答では当時の関連サイトとして `mentai.org` の「プロジェクト★めんたい」と `curry.mentai.info` が提示されている。

この証言は「絵理香」までは直接結び付けるが、「K版」とは明記していない。また質問文中の開発元に関する記述は別途検証が必要なので、ホストソフト名以外の部分をそのまま事実認定しない。

Source:
https://q.hatena.ne.jp/1116439578

### Independent evidence for SIG structure

Vectorに現存するMS-DOS用「元素名辞書」の説明には「めんたいネットＷＸ２シグ『精強無比！ＷＸ２』にて作られた一括登録用辞書」と明記されている。これにより、めんたいネットに少なくともWX2をテーマにしたSIG型コミュニティが存在したことを独立に確認できる。

Source:
https://www.vector.co.jp/soft/data/writing/se016870.html

### What is confirmed

- 名称: めんたいネット
- 地域: 福岡（記事中で「地元のISP」として言及）
- 1990年代半ば頃にパソコン通信サービスを利用できた
- ITmedia取材対象者がMS-DOSを使っていた
- 2005年の元利用者回想で、めんたいネットが「絵理香」で運用されていたと直接言及されている
- 1992年頃のChat利用を示す元利用者回想がある
- `めんたいネットWX2シグ「精強無比！WX2」` の存在をVector掲載資料で確認できる
- 2005年時点で `mentai.org` の「プロジェクト★めんたい」と `curry.mentai.info` が関連先として紹介されていた

### Oral-history lead

研究中の口述情報として「めんたいネットは絵理香K版だった」という記憶が得られている。
公開資料によって「絵理香」までの外部裏付けは得られた。ただし「絵理香K版」と明記した資料、または `ERIKA-K` の実ログはまだ未発見。K版については引き続き hypothesis とし、ログ、ホスト表示、コマンド体系、電話帳・会員資料等で確認する。
