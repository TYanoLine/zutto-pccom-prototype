# 絵理香K版 掲示板メニュー コマンド証拠台帳

- 作成日: 2026-10-09 ／ 更新: 2026-10-10
- 対象: 掲示板（BM / BX / BR / BW / 記事内の A・K・KA など）と、ファイル（FM / FX）の一覧操作。最上位メニュー・電報は付録に最小限を記載。
- 目的: どの史料が、どの版・どの局で、どの表記を示したかを区別して記録する。推測は推測として明記する。
- 扱い: 第三者ログの本文・件名・投稿者名は記録しない。画面上の操作表示（凡例・プロンプト・コマンド名）だけを残す。生ログは調査用スクラッチパッドにのみ保存し、リポジトリには含めない。

## 表記規約

- `A|B` は「A または B」（どちらでもよい、または並列の選択肢）。
- `A/B` は「A 対 B」（対になる操作。例: 次 対 前）。区切りとして `/` を使わない（「`.` / Return」は「`.`|Return」と書く）。
- `` `cr` `` は Return（キャリッジリターン）。
- 「`-`」は過去側（古い方）、「`+`」は未来側（新しい方）への移動。
- 引用（§3・付録）は史料の原文のまま。上の規約は、本文の説明と表に適用する。
- §11 の操作仕様は、史料による確定ではなく作業仕様（設計上の決定）である。

証拠区分は `AGENTS.md` の分類に従う。

- **確定** — 史料に直接表示されている。
- **確定（単一局）** — 1局・1年のログのみ。
- **推定** — 周辺文脈からの妥当な推測。直接の操作結果はない。
- **不明** — 表示はあるが意味を特定できない。
- **局固有** — 特定の局の設定や文言の可能性が高い。

## 0. 要点

1. 掲示板の中核コマンド語は、複数の年代・局で一致して現れる: `BM` `BJ` `BX` `BR` `BW`（`BWX`）`A`（アペンド） `?`|`H`。
2. **既存メモの `K` / `KA` = 既読化（Kill / Kill All）は、この調査で否定された。** 1995年ログは `[K]書き込みを消す [KA]ｱﾍﾟﾝﾄﾞを消す` と明示し、1998年ログのヘルプは `消す [BKILL]` と書く。`K` 系は「削除」である（範囲は未確定）。
3. 1996年K&Kネットの `BX` プロンプトに出る `N|B` `+-` `J` `F` `S|L` `R` `X|WX` `=` は、ラベルは確定しているが意味を説明する史料がない。`-` と `+` は、ページ送り（§11）として作業仕様を決めた。
4. 掲示板の操作凡例は、年代ごとに表記が変わる（1993 `[A]ｱﾍﾟ … [?]その他`、1995 `[A]ｱﾍﾟﾝﾄﾞ … [?]HELP`、1998 `[T/00/0]新MSG … [H] ｺﾏﾝﾄﾞ一覧 [?] 説明`）。版差か局差かは未確定。
5. 現行 `runtime.go` は、確定済みの主要コマンド（BM / BJ / BX / BR n / BW / A / 番号 / `.` / `/` / H）を実装している。`BKILL`・`K`・`KA`・`N`・`B`・`+`・`-`・`J`・`F`・`S`・`L`・`U`・`X`・`WX` は未実装。
6. 配布アーカイブ（LZH / ZIP）、マニュアル、ヘルプファイルは今回の調査で**発見できなかった**。画像の一次資料は K&Kネット 1996-12-19 の実機キャプチャ GIF 2枚のみ。
7. 1995年 `A-00025`（怪文書保存館）は、他の絵理香系ログと画面体系が異なり、本文にソフト名もない。**絵理香K版の証拠として扱うのは保留すべき**（§6）。

## 1. 方法

- 既存リポジトリの史料（`docs/research/ERIKA_K_*.md`、`docs/research/erika-k-sources/`、`apps/server/internal/hostprogram/erikak/`）を精読し、画像2枚（`kklog01.gif` / `kklog02.gif`）を目視で読み取った。
- 怪文書保存館の4ログ（D-00078 / B-00032 / A-00005 / A-00025）を `curl` で1リクエストずつ取得し、Shift_JIS（cp932）として復号。角括弧表示・プロンプト・板操作の行を抽出（投稿本文は保持しない）。
- くにびきNETのmixi掲載ログ（1998年）を取得し、EUC-JPとして復号。コマンド・モードのヘルプ画面、メイン・板メニューの凡例のみを抽出。
- Web検索とサイト索引（Vector、BBS Software Directory、ja.wikipedia「草の根BBS」、wdic、Internet Archive）を確認。結果は §8。

## 10. 追加の仮説と未確定事項（2026-10-09 追記）

### 10.1 凡例・プロンプトの既定文字列（仮説）

- 推定: 凡例とプロンプトは、既定の文字列を局ごとに部分的に書き換えて使った。一致する部分（`M` `?` `HELP` `[.]` `[/]` `[0/00/T]` など）が年代・局をまたいで残り、一部の語だけが入れ替わっている。
- 根拠: 板プロンプトの型が1995年（`(BJ\40) BOARD>M:MENU ?:HELP`）、1996年（`%BD Menu(BM)> [M]MENU [?]HELP`）、1998年（`(BJ\80) BOARD [M]=MENU [?]=HELP`）で共通。1993年の `[?]その他` と1995年の `[?]HELP` のように、語だけが入れ替わっている箇所もある。
- 未確認: 既定の文字列表（設定ファイル）の実在。同じ部品がプログラム本体の固定文字列だった可能性も残る。
- 区別する方法: 同じ版で局だけ違う2つの板画面の比較、または設定ファイルの実物。

### 10.2 追加調査で得られた所見（コマンド仕様ではない）
