## Account ID / handle research

A preserved 1999 BIG-Model ver.5 support discussion includes sender lines such as:

    NAT27811 暁の疾風

and explicitly describes an "ID + handle display mode" for boards. This strongly supports separate ID and handle fields in BIG-Model v5.

Important limitations:

- The evidence is from 1999 and BIG-Model v5, later than the project's main 1995-1996 setting.
- Japanese handles are directly observed, so the project-wide ASCII-only handle restriction is intentionally a service rule, not a claim about historical BIG-Model.
- Exact handle length, punctuation, case rules and change behavior remain unverified.
- Do not back-port v5 rules to 1995-1996 versions without earlier evidence.
