# Generated host fields

`software_family`, `line_count`, `max_baud`, `founded_on`, `popularity`, and `member_count` are persisted as host skeleton facts. The current numeric/category distributions are fictional world-building scaffolding, explicitly not historical market statistics.

Preset hosts specify the same facts in YAML, together with definition attributes
(`listed`, `role`) that are not rolled from the seed. See `HOST_DEFINITION.md`.
