# データモデル: BBS本文の人物別具体化

| 概念 | 主な属性 | 保存・関係 | 検証条件 |
| --- | --- | --- | --- |
| 記事 `Post` | ID、ホスト、板、投稿者 ID、投稿時刻、件名、返信先、本文 | 世界の正本 | 件名と返信先を変更しない。本文確定後は再生成しない |
| 記事意図 `PostIntent` | 行動、話題、原因、状況要約・事実、`ArticleDetailsMaterialized` | 記事の正本 | 投稿行動や恒久的な人物事実を詳細から新設しない |
| 記事ローカル詳細 `article_detail` | 種別、短い事実、0〜2件 | `SituationFacts` 内で記事意図に属する | 編集指示、メタデータ、重複を拒否。件数だけで処理状態を判断しない |
| Detail 完了状態 | `ArticleDetailsMaterialized: bool` | `PostIntent` に保存し、記事スナップショットと共に永続化 | `true` は検証済み0〜2件を保存済み、`false` は未実行または失敗。失敗理由は運用記録であり世界事実にしない |
| 本文 `Post.Body` | 最終文面 | 記事へ保存 | 空本文と未確定事実を受け入れない |
| 人物 `Persona` | ID、役割、関心、文体、日常の基線 | 投稿者の背景 | 基線だけを今回の投稿原因にしない |
| 人物事実 `PersonaFact` | 人物 ID、キー、値、確定時刻 | 人物の正本 | 投稿時刻より後の事実を使用しない |
| 人物履歴 `AuthorHistory` | 過去記事の件名、本文または確定済み意味情報 | 一時文脈 | 同一ホスト・人物、過去のみ、最大6件、同一スレッドを除外 |
| スレッド文脈 `ThreadContext` | 応答先と先行返信 | 一時文脈 | 他人の経験を返信者本人へ移さない |

## 関係

1. 記事は投稿者と記事意図に結び付く。応答先の因果関係とホスト固有の表示上の親子関係・件名は別に扱う。
2. 人物履歴は投稿者の過去記事から一時的に選ぶ。未生成の古い本文は新たに作らず、記事意図の意味情報を使う。
3. 記事ローカル詳細は人物の恒久的な事実へ昇格しない。評価 Lab のアーカイブも世界正本へ戻さない。
4. `ArticleDetailsMaterialized` は呼び出し元やホスト種別の状態ではなく、記事単位の正本状態。通常閲覧と Lab の隔離コピーで同じ意味を持つ。

## 状態遷移

```text
選択済みヘッダー・意図（本文なし）
  → 時点有効な人物事実と過去発言を収集
  → 記事ローカル詳細を0〜2件確定・保存
  → 必要なスレッド先行本文を確定
  → 最終本文を生成・検証・保存
  → 後続の閲覧は保存済み本文を返す
```

- 詳細提案失敗: 限定再試行後、元の記事を維持する。
- 0件の詳細: 詳細なしの完了状態を正本へ保存し、再閲覧・再起動後も再呼び出しで勝手に変更しない。
- Detail 生成失敗: 完了状態を保存せず本文にも進まない。限定再試行後に失敗表示し、次回閲覧で再試行できる。
- Detail 保存失敗: メモリ上の提案を本文へ渡さず、完了状態を `false` のままにする。
- 旧記事: 本文が空で完了状態が `false` なら初回閲覧で処理する。本文済みなら完了状態が `false` でも再処理しない。
- 本文失敗: 確定済み詳細を維持し、次の試行で別の詳細を作らない。
- 同時閲覧: 同じスレッドで異なる本文・詳細を競合して採用しない。
